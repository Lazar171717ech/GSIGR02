## Estructura del Proyecto
* `src/GSILabs/BModel`: Modelo de dominio e implementación de `XMLRepresentable` (Práctica 01 y Práctica 03 - Ejercicio 1).
* `src/GSILabs/BSystem`: Lógica de negocio (`BusinessSystem`), importación ODS y persistencia/carga XML (Prácticas 01, 02 y 03 - Ejercicios 2 y 5).
* `src/GSILabs/persistence`: `XMLParser` y `XMLParsingException` para el análisis y validación de representaciones XML (Práctica 03 - Ejercicios 3 y 4).
* `src/GSILabs/serializable`: Interfaz `XMLRepresentable`.
* `test/Pruebas`: Clases de prueba (`P03Tester`, `P03Ej01Tester`, `P03HardcoreTester`).
* `P03Ej01Gr02.pdf`: Informe justificativo del diseño de relaciones en XML (Ejercicio 1, < 400 palabras).
